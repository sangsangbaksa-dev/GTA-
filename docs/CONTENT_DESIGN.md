# 컨텐츠 기획서 — Project Harbor: 전투 · 경제 · 멀티플레이

> 무대: 가상의 항구 도시 **Port Calloway**. 모든 이름·조직·브랜드는 오리지널.
> 이 문서는 "무엇을 만드는가"를, `ARCHITECTURE.md`는 "어떻게 만드는가"를 다룬다.
> 수치는 초기값이며 실제 값은 `data/` JSON에 있다. 여기 숫자를 바꾸면 JSON도 같이 바꾼다.

---

## 1. 한 줄 요약

**최대 16명이 같은 도시에 들어와, 2~4인 크루를 짜서 총격전으로 돈을 벌고(더러운 돈), 세탁해서(깨끗한 돈) 장비·아지트·사업에 재투자하는 3인칭 커버 슈터 온라인.**

### 디자인 기둥
1. **총격전이 재미의 본체** — 커버, 측면, 제압 사격. 모든 돈벌이는 결국 교전 하나로 수렴한다.
2. **돈에는 무게가 있다** — 현금은 들고 다니면 털릴 수 있고(죽으면 떨어뜨림), 세탁해야 안전하다. 위험을 감수할지 매 순간 결정.
3. **같이 하면 더 번다, 남의 것을 뺏을 수도 있다** — 협동(습격)과 경쟁(구역전·보급 쟁탈·현상금)이 한 도시에 공존.
4. **공정한 서버** — 피해·돈·아이템은 전부 서버가 판정. 클라이언트는 입력만 보낸다.

## 2. 핵심 루프

```
 ┌──────────── 30초 루프: 교전 ─────────────┐
 │ 커버 → 엿보기·사격 → 재장전/이동 → 측면/제압 │
 └──────────────────┬─────────────────────┘
                    ▼
 ┌──────────── 10분 루프: 일거리 ────────────┐
 │ 의뢰 수락 → 이동(차량) → 교전 → 전리품 운반 │
 │ → 도주(수배) → 은신처 도착 = 더러운 돈 확보 │
 └──────────────────┬─────────────────────┘
                    ▼
 ┌──────────── 세션 루프(1~2시간) ───────────┐
 │ 세탁(사업체) → 깨끗한 돈 → 무기·개조·방어구 │
 │ → 크루 평판 상승 → 더 큰 습격 해금           │
 └──────────────────┬─────────────────────┘
                    ▼
 ┌──────────── 장기 루프(주 단위) ────────────┐
 │ 구역 장악 → 사업체 확장 → 수동 수입 → 시즌 순위 │
 └─────────────────────────────────────────┘
```

## 4. 전투 설계

### 4.1 생존 수치
| 항목 | 값 | 비고 |
|---|---|---|
| 체력 | 100 | 6초 무피격 시 초당 8씩 **50까지만** 자동 회복. 50 이상은 구급상자로 |
| 방어구 | 0~100 | 피해의 **60%를 흡수**, 흡수량만큼 방어구 소모. 헤드샷은 방어구 무시 |
| 다운(DBNO) | 협동 시 | 체력 0 → 20초간 기어다님, 동료가 3초 홀드로 부활(체력 30). PvP 상대에게는 다운 없음(즉사) |
| 리스폰 | 10초 | 가장 가까운 은신처 또는 크루원 근처(교전 중이 아니면) |

### 4.2 부위·거리·관통
- 부위 배율: 머리 ×(무기별 `headshotMultiplier`, 기본 2.0), 몸통 ×1.0, 팔다리 ×0.75.
- 거리 감쇠: `falloffStart`까지 100% → `falloffEnd`에서 `minDamageScale`로 선형 감소.
- **재질 관통**: 소품·건물 재질 태그로 결정 (`data/combat/materials.json`).
  | 재질 | 관통 | 관통 후 피해 |
  |---|---|---|
  | 콘크리트·흙(모래주머니)·금속(컨테이너·금고) | ✕ | — |
  | 나무(상자·팔레트) | 소총만 | 50% |
  | 얇은 금속(드럼통·쓰레기통·자판기) | 소총·SMG | 60% |
  | 유리 | 전부 | 85%, 유리 파괴 |

### 4.3 커버
- 소품 태그 `cover_low`(~0.8m, 웅크리면 완전 엄폐, 머리 위로 사격) / `cover_high`(~1.2m+, 옆으로 엿보기) / `cover_full`(벽).
- **엿보기 노출**: 엿보는 동안만 피격 판정 부위가 드러남. 서버가 커버 상태를 알고 있어서 "커버 뒤에서 맞았다"는 억울함을 줄인다.
- 폭발물(`explosive` 태그: 빨간 드럼통, 가스통 보관함): 체력 30, 피격 시 반경 5m 폭발(중심 120 → 가장자리 20), 연쇄 폭발.

### 4.4 제압(Suppression)
- 캐릭터 주변 1.5m 안으로 탄이 지나가면 제압 게이지 상승 → 화면 흔들림·조준 탄퍼짐 ×1.5. NPC는 제압되면 커버로 숨는 확률↑.
- 목적: 혼자 영웅 플레이보다 "한 명이 누르고 한 명이 돌아간다"를 보상.

### 4.5 무기 (`data/weapons/*.json`)
| ID | 분류 | 역할 | 가격(깨끗한 돈) | 해금 평판 |
|---|---|---|---|---|
| `kestrel_p10` | 권총 | 기본 지급, 보조 | 0 | 0 |
| `wasp_smg` | SMG | 근거리 돌파 | 2,400 | 1 |
| `breaker_12` | 산탄총 | 실내·문 앞 | 3,100 | 2 |
| `halberd_ar` | 소총 | 중거리 주력, 관통 | 5,800 | 3 |

- **탄약은 돈이 드는 소모품**(경제 싱크). 권총 탄 15발 $40 ~ 소총 탄 30발 $120. 탄약 상자 픽업은 무료지만 위치가 공개됨.
- **개조**(작업대 `prop_workbench`): 확장 탄창, 소음기(소음 반경 ×0.4, 데미지 ×0.9), 조준경(조준 탄퍼짐 ×0.7), 손잡이(반동 ×0.8). 각 $800~2,500.
- 무기는 사망해도 잃지 않는다(좌절감 방지). 잃는 건 **들고 있던 현금**.

### 4.6 적 AI 개요
유틸리티 AI 행동: `TakeCover`, `Advance`, `Flank`, `Suppress`, `Charge`, `Retreat`, `Reload`. 아키타입별 가중치는 `data/ai/`. 플레이어 수에 따라 스폰 수·체력 스케일 (1인 ×1.0, 2인 ×1.5, 3인 ×1.9, 4인 ×2.2).

## 5. 경제 설계

### 5.1 화폐 두 종류
| 화폐 | 얻는 법 | 쓰는 곳 | 위험 |
|---|---|---|---|
| **더러운 돈(Dirty)** | 강도·습격·구역 수입·보급 상자 | 암시장(탄약·방어구·소모품), 세탁 | 지갑에 있으면 **죽을 때 일부 떨어뜨림** |
| **깨끗한 돈(Clean)** | 세탁, 합법 의뢰, 사업체 배당 | 무기·개조·차량·아지트·사업체 | 은행 보관, 안전 |

- 더러운 돈은 **지갑**에만 존재. 은신처 금고에 넣으면 사망 시 안 떨어지지만, 세탁 전까지는 무기 상점에서 못 쓴다.
- 깨끗한 돈은 **은행**(ATM·폰). 지갑에 꺼낼 필요 없음(카드 결제 개념).

### 5.2 사망 시 드롭
- 지갑의 더러운 돈 **25%**를 `prop_cash_bag`으로 떨어뜨림(최소 $100, 최대 $25,000). 누구든 주울 수 있음.
- 다른 플레이어가 죽였으면 그 플레이어 근처에 떨어짐 → PvP 동기. 크루원은 30초간 우선권.
- **은신처 금고 입금**: 은신처 안에서만, 3초 상호작용.

### 5.3 세탁
- 사업체(프런트)에서 더러운 돈 → 깨끗한 돈. 수수료와 처리 속도가 사업체마다 다름.
  | 사업체 | 지역 | 수수료 | 처리량(시간당) | 가격 |
  |---|---|---|---|---|
  | 동전 빨래방 | Old Mill | 30% | $20,000 | $40,000 |
  | 부둣가 수산물 도매 | Harbor Front | 22% | $45,000 | $120,000 |
  | 갤러리 | Glass Heights | 15% | $90,000 | $350,000 |
- 처리 중인 돈은 사업체 금고에 쌓임 → NPC/다른 크루의 **습격 방어 이벤트** 발생 가능(오프라인 중에는 발생 안 함).
- 세탁 전 단계 없이 즉시 쓰고 싶으면 **Velvet Hand 즉석 세탁**: 수수료 45%.

### 5.4 수입원(Faucet)과 지출(Sink)
| 수입원 | 기대 수익(4인 기준, 분당) | 비고 |
|---|---|---|
| 상점 강도 (계산대) | $600 | 솔로 가능, 짧음 |
| ATM 해킹 | $900 | 노트북 필요, 수배 2단계 |
| 보급 상자 쟁탈 | $1,200 | 공개 이벤트, PvP |
| 밀수 운반 의뢰 | $1,000 | 차량 운전 + 교전 |
| 습격 피날레 | $2,500~4,000 | 준비 미션 포함하면 $1,800 |
| 구역 수동 수입 | 지역당 시간당 $6,000 | 크루 금고로, 방어해야 유지 |
| 현상금 | 대상의 현상금 | 수배 4+ 플레이어 |

| 지출 | 규모 | 목적 |
|---|---|---|
| 탄약·방어구·구급상자 | 교전당 $200~800 | 상시 싱크 |
| 세탁 수수료 | 15~45% | 가장 큰 싱크 |
| 무기·개조 | 일회성 | 진행감 |
| 차량 수리·보험 | $300~2,000 | 운전 리스크 |
| 사업체 유지비 | 일당 매출의 5% | 장기 싱크 |
| 경찰 체포 벌금 | 지갑 더러운 돈의 40% | 수배 리스크 |

- **인플레이션 방어**: 서버가 시간당 플레이어별 수입을 기록. 동일 활동 반복 시 보상 감쇠(같은 의뢰 3회째부터 −20%씩, 최소 40%), 1시간 뒤 회복. 경제 지표(총 통화량, 싱크/수입 비율)를 서버 로그로 남긴다.

### 5.5 거래 규칙 (서버 권한)
- 모든 돈 변화는 **원장(Ledger) 트랜잭션**: `{txId, from, to, amount, currency, reason, tick}`. 이중 기입이라 합계가 항상 보존된다.
- 같은 `txId`는 두 번 적용되지 않음(재전송·복제 버그 방지).
- 클라이언트는 "구매 요청"만 보냄. 가격·잔고·재고 판정은 서버.
- 플레이어 간 직접 송금은 **크루 금고만** 허용(골드 파밍·RMT 억제). 크루 금고 인출은 크루장 권한.

## 6. 활동(컨텐츠)

### 6.1 의뢰 (Contracts) — 5~10분, 1~4인
폰 앱에서 수락. 데이터: `data/activities/contracts/*.json`.
| 의뢰 | 흐름 | 사용 소품 | 보상(더러운 돈) |
|---|---|---|---|
| **계산대 털기** | 상점 진입 → 계산대 위협/파괴 → 60초 버티기 → 도주 | `prop_cash_register` | $1,500~3,000 |
| **ATM 털이** | 노트북 설치 → 해킹 45초(방어) → 현금 다발 회수 | `prop_atm`, `prop_laptop_hack`, `prop_cash_stack` | $4,000 |
| **밀수 운반** | 부두에서 무기 상자 픽업 → 차량 → Old Mill 배달, 매복 | `prop_weapon_crate`, `prop_shipping_container` | $5,000 |
| **빚 수금** | 목표 NPC 추적 → 경호원 교전 → 서류가방 | `prop_bond_case` | $3,500 |

### 6.2 습격 (Heists) — 크루 2~4인, 준비 2~3개 + 피날레
| 습격 | 지역 | 준비 미션 | 피날레 | 총보상 |
|---|---|---|---|---|
| **Saltworks 급여일** | Old Mill | 경비 일정 해킹, 도주 차량 확보 | 공장 금고 털기, Ironclad 방어 | $60,000 |
| **블루 피어 컨테이너** | Harbor Front | 세관 서류 탈취, 크레인 조작 키 | 컨테이너 열고 현금 가방 4개 운반 | $110,000 |
| **랜턴 신탁은행** | Glass Heights | 금고 설계도, 드릴 확보, 방패 경비 정찰 | 은행 금고, 경찰 5단계 탈출 | $240,000 |

- **현금 가방 운반**: 하나당 이동속도 −15%, 달리기 불가, 들고 있으면 한 손 무기(권총)만. 떨어뜨리면 누구든 주움.
- **분배**: 피날레 완료 시 크루장이 비율 설정(최소 15%/인), 서버가 원장으로 분배.
- **재시도 비용**: 준비 미션은 유지, 피날레 실패 시 준비 1개 랜덤 소실.

### 6.3 구역전 (Turf) — 크루 vs 크루 vs NPC 세력
- 각 지역에 **구역 3개**(총 9개). 구역 깃발 지점을 60초 점유하면 장악.
- 장악한 크루는 시간당 수입 + 해당 구역 상점 10% 할인.
- 다른 크루/NPC 세력이 주기적으로 **공격 이벤트**(공지 2분 전). 방어 실패 시 소유권 이전.
- 오프라인 보호: 크루원 0명 접속이면 공격 불가, 대신 수입도 정지.

### 6.4 보급 상자 (Supply Drop) — 공개 PvPvE
- 15분마다 지도에 낙하 지점 공지(1분 전). `prop_weapon_crate` + 현금. 열기 10초(방해 시 취소).
- Ironclad 분대가 동시에 도착 → 3파전.

### 6.5 현상금 (Bounty)
- 수배 4단계 이상으로 60초 유지한 플레이어에게 자동 현상금 = 지갑 더러운 돈의 20% + $2,000.
- 사냥에 성공한 플레이어는 깨끗한 돈으로 받음(경찰 보상 개념).

### 6.6 PvP 안전장치
- **수동 모드**(Passive): 은신처에서 토글, 무기 사용 불가·피해 없음. 의뢰 수행 중에는 끌 수 없음. 전환 쿨다운 5분.
- 같은 플레이어를 10분 내 3회 이상 죽이면 공격자에게 수배 +2와 현상금(괴롭힘 억제).
- 신규 플레이어(평판 0~1)는 은신처 반경 150m 안전지대.

---

## 7. 진행(Progression)

- **개인 평판(Rep)** 0~50: 활동마다 경험치. 무기·개조·사업체 해금. 현질 없음.
- **크루 평판** 0~20: 습격·구역전으로 상승. 상위 습격, 크루 아지트 업그레이드 해금.
- **아지트(Safehouse)**: 리스폰 지점, 금고, 작업대, 옷장. Old Mill 창고(무료) → 부두 로프트($90,000) → Glass Heights 펜트하우스($400,000).
- **시즌**: 8주. 크루 순위(구역 점유 시간 + 습격 점수). 시즌 종료 시 장식 보상(돈 아님).

---

## 8. 멀티플레이 설계

### 8.1 세션
- 세션 서버 1개 = 도시 1개, **최대 16명**. 매치메이킹은 크루 단위로 같은 서버.
- **전용 서버**(데디케이티드): `Harbor.Core`를 그대로 쓰는 헤드리스 .NET 프로세스. Godot 없이 돈다 (코어가 엔진 독립이라 가능).
- 프로필(은행·무기·평판·사업체)은 서버 측 저장소에 영속. 지갑의 더러운 돈도 저장(로그아웃해도 유지, 은신처 밖에서 로그아웃하면 10% 세금).

### 8.2 권한과 동기화
| 대상 | 권한 | 클라이언트 처리 |
|---|---|---|
| 내 이동 | 서버 | **클라이언트 예측 + 서버 보정(reconciliation)** |
| 다른 플레이어·NPC | 서버 | **스냅샷 보간**(100ms 지연 버퍼) |
| 사격·피해 | 서버 | 즉시 이펙트만 표시(예측), 피해 수치는 서버 확정 후 |
| 돈·아이템·의뢰 | 서버 | 요청만 보냄, 결과 이벤트를 받아 UI 갱신 |
| 근거리 차량 물리 | 운전자 클라이언트(1차) | 서버가 속도·위치 타당성 검사 |

- 틱 30Hz, 스냅샷 20Hz, 입력은 매 틱 전송(최근 3틱 중복 포함 → 패킷 손실 내성).
- **랙 보정(Lag compensation)**: 서버가 최근 300ms의 히트박스 위치를 기록. 사격 커맨드에 담긴 "클라이언트가 보던 틱"으로 되감아 판정. 되감기 상한 250ms(그 이상 핑은 불리하게).
- **관심 영역(Interest management)**: 256m 청크 기준 반경 2청크 내 엔티티만 스냅샷에 포함. 총성은 소음 반경까지 이벤트로 전달.
- 대역폭 목표: 플레이어당 하향 ≤ 64kbps.

### 8.3 치트 방어 기본
- 클라이언트가 보내는 건 **입력과 의도뿐**. 위치·피해·돈은 받지 않는다.
- 사격 검증: 연사 속도·탄약·사선(서버 레이캐스트)·랙 보정 범위 검사.
- 이동 검증: 최대 속도 초과 시 보정.
- 경제: 원장 + 트랜잭션 멱등성 + 서버 가격표.

## 9. 소품 → 게임플레이 매핑

Set 리포 `props/manifest.json`의 `tag`로 동작을 붙인다. 게임 쪽 데이터: `data/props/props.json`.

| 태그 | 동작 | 소품 |
|---|---|---|
| `cover_low` / `cover_high` / `cover_full` | 커버 지점 자동 생성 | 방호벽, 모래주머니, 상자, 쓰레기통, 컨테이너 … |
| `explosive` | 체력 30, 폭발 | 빨간 드럼통, 가스통 보관함 |
| `vantage` | 고지대 포지션 | 비계 |
| `pickup_ammo` / `pickup_health` / `pickup_armor` | 픽업, 리스폰 60초 | 탄약 상자, 구급상자, 방탄조끼 |
| `loot_carry` / `loot_small` | 운반 전리품 / 즉시 획득 | 현금 가방, 채권 가방 / 현금 다발 |
| `supply_drop` | 보급 이벤트 상자 | 무기 상자 |
| `atm` / `register` / `safe` / `hack_terminal` | 강도·해킹 목표 | ATM, 계산대, 금고, 노트북 |
| `shop_small` / `workbench` | 구매 / 개조 | 자판기, 작업대 |
| `decor_*` | 물리·조명·앉기 | 라바콘, 가로등, 벤치 … |

## 10. 구현 마일스톤

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| **N1 네트워크 기반** | 코어 `Net` 모듈: 전송 포트, 메시지 직렬화, 서버 세션, 입력 버퍼, 스냅샷, 클라이언트 예측·보정, 보간 | 인메모리 전송으로 서버+클라 2명 시뮬레이션 테스트, 지연·손실 하에서 보정 수렴 |
| **C1 전투 규칙** | 체력·방어구·부위·감쇠·관통·폭발·다운/부활, 사격 검증, 랙 보정 히트 판정 | 단위 테스트: 데미지 표, 되감기 히트 |
| **E1 경제** | 원장(이중 기입·멱등), 지갑/은행/크루 금고, 사망 드롭, 상점·가격표, 세탁 | 단위 테스트: 보존 법칙, 중복 tx 무시, 세탁 수수료 |
| **A1 활동** | 의뢰 실행기(데이터 기반), 습격 운반·분배, 구역 점유, 보급 이벤트, 현상금, 보상 감쇠 | 의뢰 1개를 서버 시뮬레이션으로 끝까지 진행하는 테스트 |
| **G1 Godot 연결** | ENet 어댑터, 클라이언트 예측 표현, HUD(체력·방어구·지갑) | 로컬 서버 + 클라 2개 접속 |
| **S1 전용 서버** | `server/` 헤드리스 호스트, 프로필 저장소 | CI에서 서버 기동 스모크 테스트 |

N1~A1은 엔진 없이 코어+테스트로 완결되도록 만든다. Godot이 없는 CI에서도 전부 검증된다.
