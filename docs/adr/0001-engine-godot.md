# ADR 0001: 엔진은 Godot 4 (.NET, C#)

- 상태: 채택 (2026-11-24)
- 결정자: Waldo

## 맥락
대규모 오픈월드 액션 게임. 코드베이스는 Claude가 장기적으로 키운다.

## 결정
Godot 4.4+ .NET 빌드, 언어는 C#.

## 이유
- 씬·리소스가 텍스트(`.tscn`, `.tres`)라 Claude가 읽고 diff·수정 가능.
- 오픈소스라 엔진 동작을 확인·수정할 수 있음.
- C#은 엔진 독립 코어 라이브러리를 만들기 쉽다 (ADR 0002).
- 4.4부터 Jolt 물리 내장.

## 감수할 점 (우리가 직접 만들어야 하는 것)
- World Partition 같은 대규모 스트리밍 없음 → 청크 스트리밍 + 원점 이동 직접 구현.
- 대규모 군중/교통 프레임워크 없음 → 코어 Agents + MultiMesh로 구현.
- HLOD 자동 생성 없음 → 청크별 임포스터 메시를 툴로 생성.
- C# 빌드는 웹 내보내기 제한 → 타깃은 PC 우선.
