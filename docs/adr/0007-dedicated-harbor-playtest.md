# ADR 0007: 항구 플레이테스트 전용 서버

- 상태: 채택 (2026-11-25)

## 맥락

항구 플레이테스트에서 서로 다른 데스크톱 클라이언트가 같은 월드를 이용한다. 로컬 플레이와 전용 서버가 같은 충돌 배치와 게임 규칙을 적용해야 한다.

## 결정

- `HarborAuthority`가 로컬 세션과 전용 서버에서 공통으로 이동, 전투, 차량, 임무를 처리한다. 전용 서버 실행 파일은 Godot 없이 .NET 8에서 실행된다.
- LAN 플레이테스트용 연결은 `ITransport`에 TCP 프레임을 추가한다. 연결마다 순서를 유지하고, 연결 수와 메시지 크기, 큐 크기, 펌프당 처리량을 제한한다. TCP는 플레이테스트 연결에 사용하며, ADR 0004의 인터넷 규모 전송 계획은 별도로 평가한다.
- 전용 서버 기본 주소는 루프백이다. LAN에 열려면 실행 시 네트워크 주소를 지정한다.
- Windows 및 Linux 클라이언트와 Linux 전용 서버는 플랫폼별 실행 파일, .NET 런타임과 게임 데이터를 묶어 배포한다.

## 결과

- 전용 서버와 클라이언트는 같은 포맷의 항구 배치 JSON을 읽는다. 게임 규칙과 네트워크 상태는 코어 테스트에서 검증할 수 있다.
- TCP에서는 손실에 민감한 틱 상태도 같은 스트림을 공유한다. 고지연 환경의 체감과 인원수는 별도 검증이 필요하다.
