# ADR 0005: 경제 — 두 화폐 + 이중 기입 원장

- 상태: 채택 (2026-11-24)

## 맥락
기획(`docs/CONTENT_DESIGN.md` §5): 더러운 돈/깨끗한 돈, 사망 드롭, 세탁, 크루 금고. 멀티라서 복제·중복 지급 버그가 곧 경제 붕괴.

## 결정
- 돈은 `Account`(지갑·은행·은신처 금고·크루 금고·사업체 금고·시스템 계정)에 있다. 모든 변화는 `Ledger.Post(tx)`로만.
- 트랜잭션 = 같은 화폐의 from → to 이동. 생성/소멸은 시스템 계정(`sys:faucet:*`, `sys:sink:*`)과의 이동으로 표현 → **총합 보존**을 테스트로 검증 가능, 수입/지출 지표가 자동으로 나온다.
- `TxId` 멱등: 이미 적용된 ID는 무시하고 기존 결과 반환.
- 금액은 `long`(센트 없는 정수 달러). 부동소수 금지.
- 가격·수수료·보상은 `data/economy/*.json`.

## 결과
- 서버만 원장을 가진다. 클라이언트는 `BalanceChanged` 이벤트로 표시만.
- 세이브: 원장 잔고 스냅샷 + 최근 tx 로그(감사용).
