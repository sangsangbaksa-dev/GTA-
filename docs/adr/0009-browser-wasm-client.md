# ADR 0009 브라우저용 싱글플레이 클라이언트

## 맥락

Godot 4.4 .NET 프로젝트의 C# 코드는 데스크톱에서 실행된다. 설치 없이 브라우저에서 열리는 빌드에서도 운전, 전투, 교통, 경찰의 규칙과 맵 경계가 같아야 한다.

## 결정

`web/runtime`은 기존 `Harbor.Core`와 내부 루프백 세션을 .NET 8 WebAssembly로 실행한다. `BrowserHarbor`는 프레임 시간과 입력을 받고 위치, 차량, 보행자, 수배 같은 권한 상태를 반환한다. 규칙과 충돌은 C#이 담당한다.

`web/engine`은 공용 Godot 장면과 셰이더, GLB를 가져와 4.4.1 표준 에디터의 단일 스레드 Web 프리셋으로 내보낸다. Godot 렌더러는 `JavaScriptBridge`를 통해 상태를 읽는다. `web/src`의 HTML HUD와 입력 처리는 그래픽 프레임과 별도로 시뮬레이션의 고정 틱을 구동한다.

Godot과 브라우저는 같은 샌드박스 옵션으로 세션을 시작한다. `web/dist/`는 정적 HTTP 서버에서 제공할 수 있고 시뮬레이션은 브라우저 탭 안에서 진행된다. CI는 빌드와 브라우저 테스트를 실행하고 정적 파일을 아티팩트로 남긴다.

## 결과

차량과 경찰의 규칙과 3D 장면을 양쪽에서 공유한다. Godot .NET은 데스크톱 실행과 내보내기에 사용한다. 웹 빌드에서는 표준 Godot, .NET 8의 `wasm-tools`와 Node.js를 사용한다.
