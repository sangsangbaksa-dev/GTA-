# ADR 0009 브라우저용 싱글플레이 클라이언트

## 맥락

Godot 4.4 .NET 프로젝트의 C# 코드는 데스크톱에서 실행된다. 설치 없이 브라우저에서 열리는 빌드에서도 운전, 전투, 교통, 경찰의 규칙과 맵 경계가 같아야 한다.

## 결정

`web/runtime`은 기존 `Harbor.Core`와 내부 루프백 세션을 .NET 8 WebAssembly로 실행한다. `BrowserHarbor`는 프레임 시간과 입력을 받고 위치, 차량, 보행자, 수배 같은 권한 상태를 반환한다. 규칙과 충돌은 C#이 담당한다. `web/src`의 Three.js 클라이언트는 공용 월드 데이터와 GLB를 렌더링하고 키보드, 마우스 및 터치 입력을 전달한다.

Godot과 브라우저는 같은 샌드박스 옵션으로 세션을 시작한다. `web/dist/`는 정적 HTTP 서버에서 제공할 수 있고 시뮬레이션은 브라우저 탭 안에서 진행된다. CI는 빌드와 브라우저 테스트를 실행하고 정적 파일을 아티팩트로 남긴다.

## 결과

차량과 경찰의 튜닝을 `data/`에서 한 번 수정하면 양쪽에서 사용할 수 있다. 브라우저 UI와 차량 렌더링은 웹에 맞게 따로 유지한다. 웹 소스 빌드에는 `wasm-tools` 워크로드와 Node.js가 필요하다.
