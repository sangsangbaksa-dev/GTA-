# ADR 0002: 엔진 독립 코어 (포트 & 어댑터)

- 상태: 채택 (2026-11-24)

## 맥락
나중에 엔진 없이 만든 다른 게임과 합칠 예정.

## 결정
- 게임 규칙·시뮬레이션은 `core/`(순수 .NET, Godot 참조 금지).
- 엔진 기능은 `core/.../Ports/` 인터페이스로만 접근, Godot 구현은 `game/scripts/Adapters/`.
- 엔진 → 코어는 커맨드, 코어 → 엔진은 이벤트 + 상태 스냅샷.
- 코어는 고정 틱(기본 30Hz).

## 결과
- 합칠 게임은 `Harbor.Core`를 참조하고 포트만 구현하면 된다. 헤드리스(서버·테스트)로도 돈다.
- 비용: 근거리 물리처럼 엔진이 계산한 결과를 코어에 되쓰는 동기화 코드가 필요.
- 합칠 게임이 C#이 아니면(예: C++, Rust, JS) 경계 방식(네이티브 AOT 라이브러리, 프로세스 분리 등)을 별도 ADR로 정한다.
