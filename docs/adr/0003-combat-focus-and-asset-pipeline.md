# ADR 0003: 전투 중심 방향 + 블렌더 절차 생성 에셋 파이프라인

- 상태: 채택 (2026-11-24)

## 맥락
사용자 요청: 오픈월드 범죄 액션이되 **전투에 더 치중**. 사람·건물·총기 등을 블렌더로 만들 것. 소품은 별도 리포(Set)에 올리라는 요청이 있었다.

## 결정
1. **게임 방향**: 3인칭 커버 슈팅이 핵심 루프. 운전·탐험은 전투 사이를 잇는 수단. 로드맵에서 전투(M4)를 M2로 당긴다.
2. **전투 규칙은 코어**(`Combat`, `Agents`의 적 AI): 데미지·거리 감쇠·방어구·탄약·커버 판정·적 전술 결정. Godot은 조준·히트 레이캐스트·애니메이션·이펙트만.
3. **에셋은 블렌더 헤드리스 스크립트로 생성** (`tools/blender/build_assets.py` → `.glb`). 스크립트가 원본(source of truth)이고 `.glb`는 산출물. 텍스트라서 Claude가 diff·수정 가능, GUI 불필요.
4. **저장 위치**: 캐릭터·총기·건물 → 이 리포 `game/assets/`. 범용 소품(`prop_*`) → `sangsangbaksa-dev/Set` 리포 `props/` (다른 게임과 공유 가능하게).
5. 무기 수치는 `data/weapons/*.json` (스키마 `data/schema/weapon.schema.json`).

## 결과
- 아트는 저폴리 플랫 컬러 플레이스홀더 수준. 나중에 수작업/외주 모델로 교체해도 이름·본·원점 규칙(`game/assets/README.md`)만 지키면 코드 변경 없음.
- (2026-11-24 갱신) 캐릭터는 메타볼 기반 연속 메시 + 자동(본 히트) 웨이트로 교체. 옷은 몸 메시를 복제·오프셋해서 만들어 웨이트를 그대로 물려받는다. 강체 바인딩은 장비(헬멧 바이저·방패 등)에만 사용.
- Set 리포를 Godot 프로젝트에 넣는 방식(서브모듈 vs 복사 스크립트)은 Godot 임포트를 붙일 때 결정.
